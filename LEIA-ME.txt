O MONOPÓLIO — SITE INICIAL

COMO ABRIR
1. Extrai o ficheiro ZIP.
2. Abre a pasta "monopolio_site" no Visual Studio Code.
3. Abre o ficheiro index.html no navegador (Chrome, Edge ou Firefox).
   Opcional: instala a extensão Live Server no VS Code e escolhe "Open with Live Server".

FICHEIROS
- index.html: estrutura e conteúdo do site
- style.css: cores, layout e adaptação a telemóvel/computador
- script.js: menu mobile e ano automático no rodapé
- assets/logo-monopolio.jpg: logótipo enviado

PERSONALIZAÇÃO
- Edita os nomes em index.html se houver alguma grafia a corrigir.
- A secção Galeria é demonstrativa; podes substituir os blocos por fotografias.
- Os cartões dos membros usam iniciais por enquanto. Para usar fotografias, adiciona imagens à pasta assets e troca o conteúdo da div "avatar" por uma tag img.
- O site é estático: não tem base de dados nem formulário de contacto funcional nesta primeira versão.
